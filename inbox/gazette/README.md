# Upload Kenya Gazette PDFs here

1. Click **Add file → Upload files** (while you are inside this `inbox/gazette` folder).
2. Drag in the Gazette PDF (or several at once) and click **Commit changes**.
3. Within a few minutes the issue appears on www.rmc-advocates.com/gazette.html, searchable,
   with its own page and listed in the sitemap. The PDF is moved out of this folder automatically.

If the volume, number or date cannot be read, a file ending in `.ERROR.txt` appears here explaining what to do.
