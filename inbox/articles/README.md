# Upload Insights articles here (Word .docx)

1. Write the article in Word. Make the **first line the title** (use the *Title* or *Heading 1* style),
   and use *Heading 2* for section headings. Bold, lists, tables, quotes and images are kept.
2. Optional: start the file name with the publication date, e.g. `2026-11-03 Land Control Act changes.docx`.
   Without a date, today's date is used.
3. Click **Add file → Upload files** inside this `inbox/articles` folder, drag in the .docx and click **Commit changes**.
4. Within a few minutes the article has its own page and appears under "Latest articles" on the Insights page.

To correct an article, upload the edited Word file with the same title and date; the page is replaced.
